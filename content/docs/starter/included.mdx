title: What ships
description: The product areas already built into dimah-starter, and the three that are left out.
---

dimah-starter is a pnpm and Turborepo monorepo. Node.js 22.12 or newer, pnpm 12, a PostgreSQL database, and an S3-compatible bucket for uploads are the requirements. The app starts without S3 settings. Only uploads need them. Without `RESEND_API_KEY`, verification and reset mail is printed to the server log.

## Areas

| Area          | Included                                                                                                                      |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Auth          | Email and password, Google sign-in, passkeys, two-factor with backup codes, email verification, password reset, rate limiting |
| Organizations | Create and switch organizations, invite by email, owner / admin / member, organization logo                                   |
| Admin         | Search and filter users, ban and unban, platform roles, an organizations overview                                             |
| Account       | Profile and avatar, email change, password, passkeys, two-factor, connected accounts, active sessions, theme and language     |
| Uploads       | Direct-to-bucket uploads on S3-compatible storage through [dimah-s3](/docs/s3)                                                |
| Email         | Transactional mail with Resend and React Email                                                                                |
| i18n          | next-intl, English and Persian, right-to-left layout, localized dates and numbers, translated auth errors                     |
| Product API   | An oRPC router in `@repo/api`, called in-process from Server Actions or over HTTP                                             |
| UI            | shadcn/ui on Base UI, ReUI, Tailwind CSS 4, dark mode                                                                         |
| SEO           | Metadata, an Open Graph image with right-to-left text via Takumi, sitemap, robots, JSON-LD                                    |
| Quality       | Strict TypeScript, ESLint, Prettier, Vitest, Playwright, Turborepo caching, GitHub Actions                                    |

The stack under that table is Next.js 16, React 19, TypeScript, Better Auth, Drizzle ORM, PostgreSQL, oRPC, Tailwind CSS 4, shadcn/ui, next-intl, Takumi, Resend, Turborepo, and pnpm.

## Left out

Billing, a marketing CMS, and analytics are not in the starter. They stay out so the provider can match the product.

Persian can be removed, and so can a whole dashboard area. With one locale left, the language switcher renders nothing. The layout stays valid for left-to-right and right-to-left either way. The steps are in the repository's [i18n guide](https://github.com/dimah-kz/dimah-starter/blob/main/docs/agents/i18n.md).

URLs stay English. Only labels are translated. The locale is the `NEXT_LOCALE` cookie: no `[locale]` segment and no locale prefix on the path.
