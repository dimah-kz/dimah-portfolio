Libraries and starters under [dimah-kz](https://github.com/dimah-kz).

## dimah-s3

Full-stack S3 toolkit for the React ecosystem, powered by AWS SDK v3. The server signs the upload, the browser talks to the bucket, and credentials stay on the backend. Works with Amazon S3, Cloudflare R2, and other S3-compatible stores.

[Documentation](https://s3.dimah.dev) · [Repository](https://github.com/dimah-kz/dimah-s3)

## dimah-starter

Open-source, server-first Next.js 16 SaaS starter: multi-tenant organizations and roles, Better Auth, an admin panel, Drizzle and Postgres, S3 uploads, oRPC, and English/Persian with RTL.

[Documentation](https://starter.dimah.dev) · [Repository](https://github.com/dimah-kz/dimah-starter)

## dimah-form

Backend-first form infrastructure for TypeScript servers and React clients. The library owns the typed protocol, per-response snapshots, drafts, and submit validation. The application supplies authentication, persistence, and the interface.

[Documentation](https://form.dimah.dev) · [Repository](https://github.com/dimah-kz/dimah-form)

## dimah-survey

The backend for SurveyJS. Mount it in your app, on your database. SurveyJS stays the form. Authentication and the UI stay yours.

[Documentation](https://survey.dimah.dev) · [Repository](https://github.com/dimah-kz/dimah-survey)
